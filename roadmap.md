# Roadmap: ReplyPilot WhatsApp Automation SaaS

## Phase 1: MVP Foundation
- Ship responsive dashboard with multi-business support.
- Implement deterministic AI-style automation engine.
- Add WhatsApp webhook endpoint and dashboard simulator.
- Support FAQ answering, lead extraction, appointment handling, human escalation, business-hour logic, conversation history, and basic analytics.
- Add focused automated tests and a build artifact.

## Phase 2: Pilot Readiness
- Connect Meta WhatsApp Cloud API verification and outbound message sending.
- Add hosted database persistence for businesses, FAQs, conversations, and leads.
- Add managed authentication for business owners and staff.
- Add operator notifications for escalations.
- Add usage limits by plan without full billing automation.

## Phase 3: Paid Validation
- Add subscription checkout after pricing is validated.
- Add onboarding templates for tuition, aircon, plumbing, renovation, hawker, and bakery businesses.
- Add customer-facing setup checklist for WhatsApp credentials and FAQ import.
- Add basic export of leads and conversation summaries.

## Deferred
- Voice note transcription
- Multi-language automation
- CRM integrations
- AI quotation generation
- Calendar synchronization
- Native mobile app
- Website chat widget
- Broadcast messaging
- AI follow-up reminders
- Team inbox
- Customer tagging
- Enterprise workflows and white-labeling
