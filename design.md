# Design: ReplyPilot WhatsApp Automation SaaS

## Product Shape
ReplyPilot is a responsive SaaS dashboard for small business WhatsApp automation. The first screen is the actual operating console rather than a marketing landing page.

## Information Architecture
- Sidebar: product identity, business selector, main navigation, WhatsApp connection status.
- Overview metrics: auto-replies, qualified leads, human escalations, and after-hours saves.
- Inbox: conversation list with lead status and message history.
- Automation: webhook simulator, AI workflow toggles, business-hours status, and FAQ knowledge base.

## Core Workflow
1. Operator selects a business.
2. Operator reviews current conversations and analytics.
3. Operator sends or receives an inbound WhatsApp message through the simulator or webhook endpoint.
4. The automation engine detects intent, matches FAQs, extracts lead fields, checks business hours, and decides whether human escalation is required.
5. The dashboard shows the new conversation, lead summary, status, and generated reply.

## Technical Design
- `server.js` serves static assets and exposes `/api/workspace`, `/api/whatsapp/webhook`, and `/health`.
- `src/core/automationEngine.js` contains deterministic business logic that is easy to test and can run without external services.
- Optional OpenAI usage is isolated behind the server adapter; when no key is present, the tested local engine is used.
- Browser state uses local storage for a low-cost MVP experience.
- `dist/` is generated by the build script and is not required for source control.

## UX Principles
- Keep the interface operational and compact for repeated daily use.
- Use familiar controls: select menus, toggles, text areas, pills, and icon buttons.
- Avoid future-scope controls that imply unavailable features.
- Keep mobile layouts single-column and readable.

## Production Notes
- Replace the simulator with Meta WhatsApp Cloud API verification and send-message calls.
- Replace local storage with a database before live multi-user deployment.
- Add managed auth before real customer data is stored.
- Add durable audit logs before handling regulated or dispute-prone conversations.
